# ⚡ Project Flux-Agent: Autonomous P2P Energy Orchestration

> A decentralized, agentic energy market where every home, EV, and battery is an autonomous agent.

## Architecture
- **Layer 1**: Data Sources (Sentinel-2, OpenCV, Federated Learning)
- **Layer 2**: Input Aggregation (Aggregated Context Models)  
- **Layer 3**: Flux-Agent Backend Core (AutoGen, FastAPI, PyPSA)
- **Layer 4**: Interactive Frontend (Next.js 16 + React Flow)

## Quick Start

### Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
